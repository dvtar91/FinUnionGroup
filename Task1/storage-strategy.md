# Типы хранилищ

| Группа сущностей | Предлагаемый тип хранилища | Обоснование |
|------------------|---------------------------|-------------|
| **OLTP** – Счёт, Карта, Кредит, Договор, Транзакция, Обращение (операционные поля) | **Реляционная OLTP‑БД** (PostgreSQL/Oracle) | Высокая согласованность, транзакции ACID, быстрый ввод‑вывод, поддержка сложных запросов |
| **MDM** – Клиент, Продукт, Тариф, Отделение/Канал, Контрагент | **MDM‑платформа** (Informatica MDM, Talend MDM или открыто‑source CUBA) | «Золотая запись», дедупликация, владение данными, управление версиями |
| **DWH** – Исторические агрегаты, регуляторные отчёты, BI‑витрины | **Колонковый DWH** (Snowflake, ClickHouse, Azure Synapse) | Оптимизирован для аналитических запросов, масштабируемость, интеграция с BI‑инструментами |
| **Data Lakehouse** – Большие наборы событийных и исторических данных (лог‑файлы, журналы, потоковые события) | **Lakehouse** (Delta Lake on Databricks, Apache Iceberg on Spark) | Комбинация атомарных записи + возможность SQL‑запросов, поддержка версии данных |
| **Объектное хранилище** – Документы, сканы, файлы выгрузок | **Object Store** (Amazon S3, Azure Blob, MinIO) | Неструктурированные файлы, масштабируемость, интеграция с Lakehouse |
| **Графовая БД** – Связи между клиентами, контрагентами, реферальные сети | **Neo4j** или **Amazon Neptune** | Быстрый путь поиска «партнёр‑клиент», AML‑аналитика |
| **Поисковый движок** – Полнотекстовый поиск по обращениям, документам, клиентским записям | **ElasticSearch** | Индексация свободного текста, фасетный поиск, автодополнение |
