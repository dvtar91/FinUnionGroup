# Классификация данных

| Сущность | Категория данных | Критичность | Влияние на ИБ | Средства защиты |
|----------|------------------|------------|--------------|-----------------|
| Клиент | ПДн + Фин. данные | Высокая | Утечка → нарушение GDPR/ФЗ‑152, штрафы, репутационный риск | Шифрование at rest, TLS in‑flight, маскирование в BI, RBAC, аудит |
| Счёт | Фин. данные | Высокая | Некорректные операции → финансовый риск | Шифрование, целостность (HMAC), контроль доступа, журналирование |
| Карта | ПДн + Платёжные данные | Очень высокая | PCI‑DSS, утечка PAN → штрафы, блокировка | Шифрование PAN, tokenization, PCI‑DSS, ограниченный доступ |
| Кредит | Фин. данные | Высокая | Нарушение условий кредитования, репутация | Шифрование, подпись, аудит |
| Договор | ПДн + Юр. данные | Высокая | Несоответствие регуляторам | Шифрование, электронные подписи, контроль версий |
| Транзакция | Фин. данные | Очень высокая | AML, фрод, регуляторные отчёты | Неизменяемость, журналирование, шифрование, прослеживаемость |
| Продукт | Справочные данные | Средняя | Ошибки в тарифах → финансовые потери | Контроль версий, ограниченный доступ |
| Обращение | ПДн + Контент | Средняя | Раскрытие личных запросов | Шифрование, RBAC, хранение в защищённом хранилище |
| Контрагент | ПДн + Реквизиты | Высокая | AML, фрод | Шифрование, проверка в AML‑системе |
| Тариф/Комиссия | Справочные | Низкая | Ошибки расчётов | Контроль версий |
| Документ | ПДн + Юр. данные | Высокая | Утечка документов | Шифрование, контроль доступа, цифровая подпись |
| Отделение/Канал | Справочные | Низкая | Ошибки маршрутизации | RBAC, ограниченный доступ |
